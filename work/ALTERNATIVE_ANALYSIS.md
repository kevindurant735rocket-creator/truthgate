# ALTERNATIVE_ANALYSIS(本品 vs 最普通方案)

baseline: 最普通方案：基础CRUD页面，无空状态、无即时反馈、无亮点

差异化(CORE):
- INN-01-empty-state-guidance: baseline[空数据白屏/空白列表] → 本品[空状态直接告诉用户下一步做什么]
- INN-02-inline-error-hint: baseline[错输入崩溃或静默失败] → 本品[原地红色提示，不丢已填内容]
- INN-03-one-step-add: baseline[新增需跳页/开弹窗填多表] → 本品[首屏单行输入回车即新增]

结论: 有 3 个可感知差异点
